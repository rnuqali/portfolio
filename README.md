# Rawan Nuqali Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Before publishing

1. Open `index.html`.
2. Replace `https://github.com/yourusername` with your personal GitHub profile link.
3. If you want to add repository links for the NLP, CKD, or Referral projects, add them in the relevant project cards.
4. Keep `Rawan_Nuqali_Resume.pdf` in the same folder.

## Publish with GitHub Pages

1. Create a new public repository, e.g. `rawan-portfolio`.
2. Upload all files in this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide a public URL for the portfolio.
